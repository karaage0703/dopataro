# 🍑 ドパ太郎

**叩け。強化しろ。桁をぶっ壊せ。**

桃太郎と犬・猿・キジで、鬼の群れをまとめてぶった斬る！
万 → 億 → 兆 → 恒河沙 → 無量大数。その先はゲーム独自の「桃源」「宇宙」へ。

## まず遊べ！

[ブラウザで遊ぶ！](https://karaage0703.github.io/dopataro/)（GitHub Pages公開後）。インストール不要。

[単体HTML版](dist/dopataro.html)を保存してブラウザで開いてもOK。
スマホはHTMLを実行できるブラウザで開こう。添付のプレビューでは動かないことがあるよ。

1. **鬼をタップ！** 黄色の攻撃ボタンでもOK。
2. **小判で刀を強化！** 通常は火力2倍、5レベルごとの進化で20倍。仲間も強化しよう。
3. **18回連打で桃バースト！** 8秒間、全火力が **1億倍**！
4. **ゲージ100%で「桃神降臨」！** 犬・猿・キジと合体必殺。バーストに重ねれば **10億倍**！

## 鬼も殴ってくるぞ！

- **ライフは4人で共有。** 減ったら「きびだんご」で35回復。
- **「見切り！」が光ったら押せ！** 攻撃を防いで反撃。大鬼の結界も砕ける。
- **ライフ0はゲームオーバー。** 「最初からやり直す」で育成も小判も魂も0、第1波から。
- **500波突破は勝ち！** タップ不要で自動転生。刀・仲間・小判を引き継ぎ、ライフ全回復。魂でさらに強くなる！

## 音！ セーブ！ やり直し！

- 音は最初のタップで開始。鳴らなければ「音テスト」。音量と消音設定も確認しよう。
- 火力・小判・敵HPは「終極30乗」を超えて成長。以前のセーブも引き継げます。
- 進行は同じブラウザ・同じURLに自動保存。閉じている間は進まない。複数タブでの同時プレイは避けよう。
- 好きな時にやり直すなら、上の「最初から」→「退避して最初から始める」。前のセーブは最新1件だけ戻せる。
- 音と演出は上のボタンで切り替えられる。
- PC操作：**Space**で攻撃、**G**で見切り、**F**で桃神降臨。**1**で刀、**2**でイヌ、**3**でサル、**4**でキジを強化（テンキーも対応、1回押すごとに1レベル）。小判不足時は強化できません。
- 反撃の残り秒数とゲージを大きく表示。予告後、減るゲージが「見切り区間」に入り、**「今だ！」**が出たら見切り！

npm run check

npm run build

`src/` がゲーム本体。buildするとPagesの入口 `dist/index.html` と持ち運び用 `dist/dopataro.html` ができる。
絵も音も自作のプログラム描画・合成。

### GitHub Pagesで公開する

リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
mainへのpushで検証・build後に `dist/` を公開する。PRでは検証のみで公開しない。Actionsから手動実行する場合もmainを選ぶ。
公開先は https://karaage0703.github.io/dopataro/ 。プレイするURLが変わると、セーブは別になる。

[GitHub公式の設定手順](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)
